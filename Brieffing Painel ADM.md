Desenvolva aplicação para administração completa da produtora, utilize banco de dados gratuito, repositorio no github e deploy publico no vercel. Permita administração de artistas, contratantes e espaços de eventos assim como administração de agenda, financeiro, orçamentos e contratos, com diferentes perfis de usuários, "administrador" "financeiro" "artista" "contratante". Gere automaticamente via API do Google Drive os artefatos padrões por evento como orçamentos, propostas, contratos e ficha cadastral por evento, os mesmo devem editaveis via painel administrativo da produtora, permita também a atualização dos artefatos como Cronogramas, checklists de pré produção e controle de horas por atividade.
